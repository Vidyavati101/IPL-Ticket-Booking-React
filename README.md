# IPL Ticket Booking - React

A simple IPL Ticket Booking UI built using React JS and Vite.

## Technologies Used

- React JS
- JavaScript
- JSX
- Vite
- Git & GitHub

## Concepts Used

- React Components
- JSX
- Props
- State
- Array map()

## Features

- Navigation bar
- Hero section
- Upcoming IPL matches
- Match details
- Ticket booking form
- Footer
